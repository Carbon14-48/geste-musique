comment jouer

Reculez jusqu'à voir vos deux coudes dans l'image, avec la lumière devant vous. Mettez un casque.

main gauche · les accords

  • 1, 2, 3, 4 doigts : accords I, II, III, IV de la tonalité
  • main ouverte : V · cornes (index + auriculaire) : VI · cornes + pouce : VII
  • dos de la main : le même accord en mineur / majeur parallèle
  • doigts vers le bas : l'accord descend d'un demi-ton
  • hauteur : bas = triade, plus haut = 7e, 9e, 13e (en direct)
  • tourner le poignet : filtre et longueur des notes
  • lâcher la pose arrête l'accord ; la refaire le rejoue

main droite · l'arc des modes

  • poing, dos à la caméra : l'arc apparaît
  • glisser à gauche / à droite : choisir une case
  • ouvrir la main paume vers la caméra : valider · dos vers la caméra : annuler

les 5 modes

  • batterie : pincez pouce + index (grosse caisse), majeur (caisse claire), annulaire (charleston), auriculaire (toms) ; tournez le poignet pour le niveau : silence → base → fantômes → groove → roulements. Lâchez : ça continue.
  • basse : les 4 pincements règlent densité, notes, octaves et groove (tresillo, galop) ; la hauteur règle la résonance.
  • mélodie : la hauteur choisit la note, le pincement la tient ; un son par doigt.
  • fx / dj : delay, réverb, stutter, crush, actifs tant que vous pincez ; le poignet règle l'effet.
  • sculpt : arpège, enveloppe, trémolo, grain ; la hauteur ouvre le voicing des accords.

Un pincement ne compte que si la main est immobile et qu'un autre doigt est levé.
